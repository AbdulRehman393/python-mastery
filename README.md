# 🐍 Python Mastery

A structured, hands-on Python learning journey covering the fundamentals, intermediate concepts, object-oriented programming, API integration, practical exercises, and beginner projects.

This repository documents my progress while learning Python through small examples, interactive programs, visual notes, and real-world practice.

## 📚 What You Will Learn

- Python syntax and program structure
- Variables, data types, and type casting
- User input and formatted output
- Strings and string manipulation
- Conditional statements and boolean logic
- Lists, sets, tuples, dictionaries, and 2D collections
- Functions, arguments, return values, and docstrings
- Lambda functions and `map()`
- `for`, `while`, and nested loops
- Object-oriented programming
- Classes, objects, inheritance, abstraction, and polymorphism
- Exception handling and input validation
- Modules and packages
- Decorators
- HTTP requests and REST APIs
- Headers, status codes, query parameters, and authentication
- Command-line exercises and beginner projects

## 🚀 Getting Started

### Prerequisites

- Python 3.11 or newer
- Git
- Basic command-line knowledge

### Clone the repository

```bash
git clone https://github.com/AbdulRehman393/python-mastery.git
cd python-mastery
```

### Install the external dependency

Most examples use only Python's standard library. The API examples require `requests`:

```bash
python -m pip install requests
```

### Run an example

```bash
python 01_basics/01_display.py
```

### Run an exercise

```bash
python 09_mini-exercises/17_countdown_timer.py
```

### Run a project

```bash
python 11_projects/beginners/quiz_game.py
```

### Run the API example

```bash
python 10_beyond-basics/api.py
```

## 🎯 Suggested Learning Path

1. Start with `01_basics`
2. Continue with `02_control-flow`
3. Study `03_data_structures`
4. Practice reusable code in `04_functions`
5. Learn iteration in `08_loops`
6. Complete exercises in `09_mini-exercises`
7. Study OOP in `05_oop`
8. Learn error handling in `06_exception-handling`
9. Explore modules and decorators in `10_beyond-basics`
10. Build larger applications in `11_projects`

## 🧪 Validation

The repository currently contains standalone learning scripts rather than a formal test suite.


Some programs require interactive input, while API examples may require an internet connection.
